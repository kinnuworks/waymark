How it works

Two walks make the map. One phone follows it.

A printed ChArUco board at the entrance gives every walker the same origin and a metric scale, so separate walks line up without anyone measuring by hand.

1

Map the building

Fix the board at the entrance, 1.2 m up. Two volunteers start there and walk the floor for about 15 minutes, marking rooms, doors, stairs, lifts and exits as they pass them. The server splits the unmapped areas between them.

2

Build the map

The server refines both walks with bundle adjustment, merges them where they overlap, and draws a floor plan with a route graph between the marked places.

3

Guide a visitor

The visitor picks a destination. Every second the phone sends a camera frame. The server finds the phone's position and heading on the map and replies with the next spoken instruction.

Confidence agent

When it isn't sure, it says so.

An agent on the server checks localisation confidence on every frame. Each decision goes into a trace with what it saw and why it acted, and the helper console shows that trace live.

  • If the camera sees too little to match, it asks the visitor to pan the phone slowly.
  • It prefers a route with fewer turns, even when that route is a little longer.
  • Near stairs it asks the visitor to stop until the position is confirmed.
  • If it still can't place the visitor, it asks a human helper to come over.

Architecture

How a frame travels.

Phones do no vision work. They send a JPEG about once a second and speak the reply, so any recent phone browser can take part.

Client

Phone browser

Rear camera, compass and speech. The mapping app is for volunteers; the guidance app is for visitors.

JPEG, 960 px, ~1 per second
Edge

CloudFront

HTTPS for the camera, the static web app, and the API path forwarded to the worker.

  • solvePnP with MAGSAC for camera pose
  • Triangulation and bundle adjustment
  • Merging several walkers into one map

Safety

Waymark works alongside a cane or guide dog. It never replaces them.

  • It gives directions on a map of fixed walls, doors and stairs. People, trolleys, open doors and wet floors are not on that map, so the cane or dog still does that job.
  • When its confidence drops it says so out loud and asks the visitor to wait or pan the phone.
  • Near stairs it asks the visitor to stop until the position is confirmed.
  • A Call a helper button is on screen at all times, and the agent calls one itself when it cannot place the visitor.
  • If the phone loses its connection to the server, it tells the visitor to stop and wait.
